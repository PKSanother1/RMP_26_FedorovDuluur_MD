# Изучение основ и работы с Expo 

> **Expo** — это полноценная платформа и экосистема на базе React Native, предназначенная для разработки, сборки и развертывания универсальных приложений на JavaScript и TypeScript. Она позволяет создавать один проект, который будет нативно работать сразу на Android, iOS и в веб-браузерах. Фреймворк предоставляет маршрутизацию на основе файлов, стандартную библиотеку нативных модулей и многое другое.
---

## Создание проекта
 Рекомендуется с помощью, [create-expo-app](https://docs.expo.dev/more/create-expo/). Проект по умолчанию включает примеры кода, которые помогут начать работу.

### create-expo-app 
> Инструмент командной строки для создания нового проекта в Expo и React Native. 
---
Это инструмент командной строки для создания и настройки новых проектов Expo и React Native. Он упрощает процесс инициализации, предоставляя различные шаблоны для быстрого начала работы без необходимости ручной настройки.

---
### Для создания нового проекта выполняем команду:
```bash
npx create-expo-app@latest      # npm
```
---
**P.S.** Вы можете выбрать другой шаблон, добавив соответствующую [--template опцию](https://docs.expo.dev/more/create-expo/#--template).

### Создание проекта из готового примера
Если вам нужен не чистый проект, а пример с конкретной технологией (например, с готовой камерой или виджетами), можно развернуть приложение из репозитория примеров Expo.
- Интерактивный выбор из списка:
```bash
bashnpx create-expo-app@latest --example
```
- Скачать конкретный пример напрямую (например, с виджетами):
```bash
bashnpx create-expo-app@latest --example with-widgets
```

## Выбор среды разработки
**Настроить локальную среду разработки**: чтобы начать создавать приложения с помощью Expo и запускать их на Android и iOS.

*Реальные устройства:*  
- Устройство Android — физический смартфон или планшет на базе Android.
- Устройство iOS — физический iPhone или iPad.

*Виртуальные устройства (Эмуляторы):*
- Эмулятор Android — виртуальный смартфон, запускаемый на компьютере через Android Studio.
- Симулятор iOS — виртуальный iPhone, запускаемый на macOS через Xcode.

**Выбор рабочего процесса (workflow)**: В зависимости от цели и маштаба проекта, выбираем подходящий вариант запуска.

## Expo GO
> Площадка для студентов, учащихся и новичков, позволяющая максимально быстро опробовать Expo.

- Назначение: Быстрое тестирование и освоение основ React Native/Expo.
- Ограничения: Это экспериментальное приложение. Оно имеет лимиты по интеграции нативных библиотек и не подходит для создания проектов промышленного (production) уровня.

## Сборка для разработки
> Cборка собственного кастомного приложения, включающая в себя полноценные инструменты разработчика Expo.

- Назначение: Предназначено для серьезных проектов, находящихся в производстве (production).
- Преимущества: Создание собственной конфигурации приложения, полная поддержка пользовательских нативных модулей и сторонних библиотек.

## Начало разработки
> Внесите первое изменение в проект Expo и увидите его в действии на своем устройстве.

**Шаг 1. Запуск сервера разработки** Для запуска сервера разработки выполняем следующую команду:

```bash
npx expo start      # npm
```

**Шаг 2. Открываем приложение на своем устройстве** После выполнения команды выше в терминале появляется QR-код. Сканируем его, чтобы открыть приложение на вашем устройстве. 
> Если используем эмулятор Android или симулятор IOS, нажием на `А` или `I` соотсвественно, чтобы открыть приложение.

**Шаг 3. Делаем первое изменение** Откройте файл src/app/index.tsx в редакторе кода и вносим изменения.

*src/app/index.tsx*
```diff 
     <ThemedView style={styles.heroSection}>
       <AnimatedIcon />
       <ThemedText type="title" style={styles.title}>
-      Добро пожаловать на Expo!
+      Привет, мир!
       </ThemedText>
     </ThemedView>
```

**Шаг 4. Структура файлов** Ознакомится с структурой файлов по умолчанию:

```text
├── src/
│   ├── app/                # Главная папка приложения (маршрутизация)
│   ├── components/         # Переиспользуемые компоненты
│   ├── constants/          # Константы (цвета, шрифты и т.д.)
│   └── hooks/              # Кастомные React-хуки
├── assets/                # Статические файлы (картинки, шрифты)
├── scripts/                # Вспомогательные скрипты автоматизации
├── app.json                # Главный конфигурационный файл Expo
├── package.json            # Зависимости и скрипты проекта
└── tsconfig.json           # Конфигурация TypeScript
```

#### Подробнее о каталоге `src/app/`
Содержит файловую навигацию приложения:
* `src/app/index.tsx` — первый (главный) маршрут приложения.
* `src/app/explore.tsx` — второй маршрут (экран поиска/обзора).
* `src/app/_layout.tsx` — файл макета, который настраивает нижний навигатор вкладок с помощью компонента `AppTabs`.

### Как сбросить проект (Опционально):
   Если необходимо полностью удалить шаблонный код, чтобы начать свой проект с чистого листа. Для этого выполняем команду:
   
   ```bash
   npm run reset-project
   ```
   > *Эта команда автоматически перенесет текущие файлы из папки `app` в архивную папку `app-example`, а затем создаст чистую директорию `app` с новым базовым файлом `index.tsx`.*
